# Documentos técnicos específicos

Esta carpeta contendrá un documento por parte concreta del código o de los datos.
Solo se crearán cuando esa parte vaya a diseñarse; no se generarán documentos
vacíos para sistemas futuros.

Cada documento seguirá la
[metodología de desarrollo](../../metodologia-desarrollo.md) y será la fuente de
verdad de los contratos, datos, comportamiento, errores y pruebas de su alcance.
